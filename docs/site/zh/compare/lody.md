# Solo 和 Lody

[← 比较总览](index.md)

[Lody](https://lody.ai/docs/quickstart/) 是面向团队的 agent 工作区：几个人共享同一个工作区，一起看 agent 的进展。

> 信息截至 2026 年 11 月初，以 Lody 官方为准。

## Lody 做得更好的

- **团队协作。** 工作区可以共享，几个人一起看、一起审。Solo 是单人工具，不做团队功能。
- **手机端**，在 iPhone 上还支持实时活动（Live Activities）。
- **agent 不会因为关窗口而中断**，由守护进程托管。
- **审阅**可以按轮也可以看整个会话，支持行评论；还能在页面上标注元素发给 agent。
- 多平台。

## Solo 不一样的地方

- **不需要账号。** Lody 需要登录；Solo 不注册、不登录，也不发送遥测。
- **编辑器。** Lody 主要是浏览文件，编辑要交给外部编辑器；Solo 内置完整的 Zed 编辑器，语言服务器、跳转、调试器都在。
- **审阅时的诊断增量**：一轮结束后告诉你这一轮新增了几个错误和警告。
- **agent 跑在你自己的终端里**，用你自己的命令行工具和订阅。

## 怎么选

团队一起用：Lody。一个人、不想登录、项目要靠完整的编辑器来读：可以试试 Solo。
