# Solo 和 Orca

[← 比较总览](index.md)

[Orca](https://github.com/stablyai/orca) 是目前用户最多的开源 ADE（agent 开发环境），由一家 YC 公司开发，更新很快。

> 信息截至 2026 年 11 月初，以 Orca 官方为准。

## Orca 做得更好的

- **agent 不会因为关窗口而中断。** 后台守护进程持有终端，退出、自动更新重启、应用崩溃都能扛过去。Solo 现在做不到。
- **功能面更广。** 手机端、内嵌浏览器（可以点选页面元素发给 agent）、为二十多种 agent 安装 hooks。
- **多平台，Windows 版已签名。** Solo 只有 Windows 版，还没签名。
- **更成熟。** 用户多，问题被发现和修复得也快。

## Solo 不一样的地方

- **编辑器。** Orca 用 Monaco，它的 issue 区里点赞最多的需求有一大半是编辑器能力：多仓库同时看 diff（#1099）、"查找引用"返回空（#961）、希望内嵌 VS Code（#7754）。Solo 本身就是 Zed：语言服务器、跳转、引用、调试器、多窗口都是现成的，跨仓库的 agent 任务也支持。
- **按轮审阅。** Orca 有行批注和 PR 流程；Solo 额外记录 agent 的每一轮，可以逐块保留或拒绝、回滚到某一轮之前，并告诉你这一轮新增了几个错误。
- **agent 跑在你自己的终端里。** 用你自己装的 Claude Code、Codex 等命令行工具和订阅，Solo 只为单次会话加 hooks，不改你的配置。

## 怎么选

需要手机端、内嵌浏览器、或者 agent 绝不能被打断：Orca。主要时间花在读代码、审 agent 的改动，项目离不开完整的语言服务器：可以试试 Solo。两者也可以一起用，agent 本身不绑定任何一边。
