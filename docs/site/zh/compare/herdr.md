# Solo 和 Herdr

[← 比较总览](index.md)

[Herdr](https://github.com/herdrdev/herdr) 是一个为 agent 设计的终端复用器：一个 Rust 写的程序，在终端里分屏管理多个 agent，另有桌面版。

> 信息截至 2026 年 11 月初，以 Herdr 官方为准。

**Solo 用了 Herdr 的成果：** Solo 判断二十多种 agent 状态的屏幕规则，就来自 Herdr（Apache-2.0 许可），保留了原来的版权和许可声明。感谢 Herdr 的维护者。

## Herdr 做得更好的

- **轻和快。** 一个程序，在任何终端里都能用，也能通过 SSH 在远程机器上用。
- **连后台服务重启都能扛过去：** 重启后恢复布局、继续会话。Solo 也能让 agent 熬过退出和更新，但如果某个终端的后台进程自己出了问题，那个会话就结束了（Solo 会提示继续上次的会话）。
- **对外接口**：CLI 和 socket API，还有 agent 主动上报状态的协议。
- **多平台**（Windows 版目前是测试版）。

## Solo 不一样的地方

- **有编辑器。** Herdr 不带编辑器；Solo 内置完整的 Zed，读代码、跳转、调试不用离开窗口。
- **按轮审阅。** Herdr 的审阅靠第三方插件；Solo 自带：逐块保留或拒绝、回滚、诊断增量、文档批注。
- **图形界面里的终端增强**：命令块、底部输入编辑器、补全、点击路径打开文件。

## 怎么选

已经习惯在终端里工作、要轻、要在远程机器上用：Herdr。需要一个编辑器来读懂 agent 的改动：可以试试 Solo。
