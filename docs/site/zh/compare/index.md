# Solo 和其他 agent 工具比较

[← 首页](../index.md)

做"同时管好几个 AI agent"这件事的工具不少。这里把 Solo 和四个开源的同类工具放在一起：[Orca](orca.md)、[Paseo](paseo.md)、[Lody](lody.md)、[Herdr](herdr.md)。它们都很活跃，很多方面比 Solo 成熟，下面会如实写出来。

> 对方的信息来自它们 2026 年 11 月初的 README、官方文档和源码，以后可能会变，以各自的官网为准。发现写错了，欢迎[提 issue](https://github.com/lucas9801/solo/issues)。

## 一句话区别

- **Orca**：功能最全的桌面 ADE，有手机端和内嵌浏览器，代码编辑器较轻。
- **Paseo**：后台守护进程加多端（桌面、手机、网页、命令行），一个人维护，很开放（CLI、SDK、MCP）。
- **Lody**：面向团队，几个人共享工作区，需要登录。
- **Herdr**：终端复用器，一个 Rust 程序，轻、快，没有编辑器。
- **Solo**：一个完整的代码编辑器（Zed）加以终端为中心的布局，重点放在**读懂和审阅** agent 的改动。

## 对照表

| | Solo | Orca | Paseo | Lody | Herdr |
| --- | --- | --- | --- | --- | --- |
| 形态 | 编辑器 + 终端 | 桌面 ADE | 守护进程 + 桌面、手机、网页、CLI | 团队共享工作区 | 终端复用器，另有桌面版 |
| 技术 | Rust（Zed） | Electron | Electron + Expo | Electron | Rust |
| 许可 | GPL-3.0 | MIT | Apache-2.0 | Apache-2.0 | Apache-2.0 |
| 代码编辑器 | 完整的 Zed：语言服务器、跳转、引用、调试器、多窗口 | Monaco，语言服务器支持不全 | 有 | 浏览文件，编辑用外部编辑器 | 无 |
| agent 在哪跑 | 你自己的终端和命令行工具 | 终端 | 守护进程；Claude 走 Agent SDK | ACP | 终端 |

## 什么时候选 Solo

- 你还要自己读代码：大仓库、C++、游戏引擎这类离不开语言服务器和调试器的项目。
- 你主要的时间花在**看 agent 改了什么、决定留不留**，而不是写提示词。
- agent 常常写计划和设计文档，你要读、批注、让它改。
- 你在 Windows 上工作。

## 什么时候选别的

- 要在手机上随时盯着、回复 agent：Paseo、Lody、Orca 都有正经的手机端。
- 关掉电脑窗口或者更新时 agent 不能断：现在的 Solo 做不到（方案已经验证，还没实现），其他四个都可以。
- 几个人一起用同一个工作区：Lody。
- 只要一个轻快的终端复用器，不需要编辑器：Herdr。
- 用 macOS 或 Linux：Solo 暂时只有 Windows 版。
