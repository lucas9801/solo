# 审阅 agent 写的文档

[← 首页](../index.md)

现在很多工作是先让 agent 写计划、设计或调研报告，你看过、提了意见、它改好了，再照着做。Solo 让这个来回在一个地方完成。

## 打开

- agent 的输出里提到 `PLAN.md` 这样的路径，点一下就在右边打开**渲染好的预览**，而不是源码。
- Mermaid 图在预览里直接画出来，可以放大查看。agent 的输出里出现 `mermaid` 代码块时，点那一行也能看图；屏幕上只显示了一部分时，Solo 会从 Claude Code 的对话记录里取完整的图。
- 图片在图片查看器里打开，代码在编辑器里打开。

## 批注

1. 在预览里选中一段文字，右键选 **批注…**，写下意见。
2. 批注列在文档下方，可以修改和删除。
3. 写完点 **发给 agent**，所有批注合成一条消息粘贴到 agent 的输入里，每条都带着它所在的行号、选中的原文和你的意见。

发给谁：如果这份文档是某个 agent 在某一轮里改的，就发给那个 agent；否则发给你最近用过的那个。

## 文档又被改了

你读过之后，agent 如果又改了这份文档，预览上方会出现一条提示：**新增了几行、删除了几行**。点 **显示改动** 会在改动过的段落旁边做标记；看完后点 **标为已读**。

这样不用重新从头读一遍，只看它改了哪里。
