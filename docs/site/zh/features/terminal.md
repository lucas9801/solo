# 终端

[← 首页](../index.md)

agent 跑在终端里，你自己也在终端里跑命令。Solo 的终端在这两件事上都下了功夫。支持 PowerShell、bash、zsh 和 fish。

## 命令块

每条命令和它的输出是一个块：有分隔线、退出码和耗时，失败的命令标红，正在跑的命令有计时，滚动长输出时命令固定在顶部。

选中块（`ctrl-up/down`，或点左边的空白处）以后，可以复制命令、输出或两者（Markdown 格式）、重新运行，或者按 `alt-enter` 把命令和输出发给另一个终端里的 agent。

## 失败了，直接交给 agent

命令失败时，退出码旁边有 **发给 agent**。Solo 只挑出真正有用的部分：编译错误和它们的位置、失败的测试和断言（支持 cargo、tsc、gcc/clang、MSVC、pytest、go、jest），其他情况取输出的最后一段，然后粘贴给在同一个目录里工作的 agent。

## 底部的输入编辑器

命令在窗口底部一个真正的编辑器里输入：可以多光标、撤销、`shift-enter` 换行，有语法高亮。

- **补全：** 用 Warp 的命令签名（约 500 个命令），子命令、带说明的选项，以及现场算出来的参数值（git 分支、npm 脚本、docker 容器……）。其余的交给 PowerShell 自己的补全。按当前目录排序，在这里跑过的命令排前面。
- **历史：** 灰色的历史建议，上下键按已输入的内容过滤，`ctrl-r` 模糊搜索。
- **`# 想做的事`：** 用中文或英文描述，Solo 让 Claude Code 生成一条命令，你看过再运行。
- **工作流：** 带 `{{参数}}` 的常用命令，`ctrl-shift-r` 调出。

## 编辑器就在旁边

- 终端里的路径点一下就打开：代码进编辑器，Markdown 进预览，图片进图片查看器。只有行号的 `:403` 会跳到上方最近提到的那个文件。
- agent 改文件时，被改的文件会在编辑器里打开，看着它改。
- 编辑器里按 `ctrl-alt-k` 把选中的代码或光标位置发给 agent，`ctrl-alt-shift-m` 发送当前文件的诊断信息。

## 重启以后

终端会按原来的位置、目录和标题重新打开（shell 是新的）。之前跑着 agent 的终端会提示继续上次的会话，比如 `claude --continue`。想连之前的输出也恢复，打开设置 `terminal.restore_contents`。
