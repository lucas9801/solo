Solo 2.5 正式版：内置浏览器，新支持 7 个 agent 的准确状态，更新改为标题栏按钮并在 Solo 里完成，另有一批安全和稳定性修复。
Solo 2.5, the first general release: a built-in browser, accurate status for 7 more agents, updates from a title bar button installed inside Solo, and a set of security and stability fixes.

[用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

Solo 现在只从 Microsoft Store 安装（Solo Code）。GitHub 上不再提供安装包和 zip；用旧安装包装的 Solo 还能用，但不再更新，请从商店安装新版。

## 新功能

- **内置浏览器：** 终端、Markdown 预览、时间线里本机地址（localhost 等）的链接在 Solo 里打开，其他网址照旧用系统浏览器（设置 › 浏览器可改）。有前进后退、地址栏、手机和平板视口、开发者工具。
- **给网页元素写批注：** 点"选取"后点网页上的元素写批注，"发送给 agent"把选择器、文字、HTML、样式和截图路径粘贴到 agent 的输入里，不自动发送。
- **让 agent 操作浏览器：** 打开 设置 › 浏览器 › 允许 agent 操作浏览器（默认关）后，Claude Code 和 Codex 能在 Solo 的浏览器里打开网页、点击、填表、截图。需要 Node.js。
- **更多 agent 的准确状态：** Gemini CLI、Qwen Code、Pi、oh-my-pi、Kilo Code CLI 通过 Solo 为每次会话加的 hooks 上报状态，不再靠读屏幕；Kimi Code CLI 和 MastraCode 在设置 `global_agent_hooks` 里开启。
- **为什么是这个状态：** 终端标签右键"为什么是这个 agent 状态？"说明状态从哪里来、最后一次上报是什么时候；agent 可以用 `solo-cli agent why`。
- **更新按钮：** 有新版本时标题栏右边出现更新按钮，不再弹通知；商店版在 Solo 里下载和安装更新，不打开商店。有 agent 在跑时可以选"退出时安装"。
- **打不开的文件：** Solo 打不开的文件（比如 .apk）显示完整路径和"在文件资源管理器中显示"按钮。

## 修复

- **安全：** shell 集成脚本放进只有你能访问的目录，按内容命名；终端托管进程的管道不让低权限程序读写；恢复会话的程序名和目录名里的特殊字符先检查或转义；读取会话记录有大小上限。
- **稳定：** 托管进程日志每天最多 8 MB；`solo-cli agent wait` 在调用它的命令退出后停下；非 Unicode 参数不再让 solo-cli 和 hook 程序崩溃。
- **任务和审阅：** 被锁住的工作树不再强删；删除任务前列出会一起删掉的被忽略文件；带 BOM 的文件在审阅里不再整行显示为改动。

## New

- **Built-in browser:** links to local addresses (localhost and friends) in the terminal, the Markdown preview and the timeline open inside Solo; other sites still open in the system browser (change it in Settings › Browser). It has back and forward, an address bar, phone and tablet viewports and developer tools.
- **Comment on page elements:** click Pick, click an element and write a comment; Send to Agent pastes the selector, text, HTML, styles and a screenshot path into the agent's input without sending it.
- **Let agents drive the browser:** with Settings › Browser › Allow Agents to Control the Browser turned on (off by default), Claude Code and Codex can open pages, click, fill forms and take screenshots in Solo's browser. Needs Node.js.
- **Accurate status for more agents:** Gemini CLI, Qwen Code, Pi, oh-my-pi and Kilo Code CLI report their status through hooks Solo adds for each session instead of being read from the screen; Kimi Code CLI and MastraCode can be turned on in the `global_agent_hooks` setting.
- **Why this status:** right-click a terminal tab and choose Why This Agent Status? to see where the status came from and when it was last reported; agents can run `solo-cli agent why`.
- **Update button:** a new version shows a button at the right end of the title bar instead of a notification; the Store edition downloads and installs updates inside Solo without opening the Store. With agents running you can choose to install when Solo quits.
- **Files Solo can't open:** files such as .apk files show their full path and a Reveal in File Explorer button.

Solo is now installed only from the Microsoft Store (Solo Code). GitHub releases no longer have an installer or a zip; Solo installed with an earlier installer keeps working but won't update, so install the new version from the Store.

## Fixes

- **Security:** shell integration scripts live in a folder only you can access and are named by their content; terminal hosts' pipes can't be used by low-integrity programs; program and folder names used to resume sessions are checked or escaped; reading session logs has a size limit.
- **Stability:** terminal host logs stop at 8 MB a day; `solo-cli agent wait` stops when the command that called it exits; non-Unicode arguments no longer crash solo-cli or the hook program.
- **Tasks and review:** locked worktrees are no longer force-removed; deleting a task lists the ignored files that go with it; files with a BOM no longer show their first line as changed in review.
