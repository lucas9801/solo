Solo 2.3：升级重启时正在跑的 agent 不再被结束，状态改用红绿灯配色，Codex 的状态终于准确。
Solo 2.3: agents keep running through an update and restart, status uses traffic-light colours, and Codex's status is finally accurate.

[用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

升级到这个版本后第一次启动 Codex，它会提示一次 "Hooks need review"，选 "Trust all and continue" 即可：Solo 给 Codex 的 hook 命令改了。

## 修复

- **更新重启会结束正在跑的 agent：** 退出得慢时，终端里的程序会被提前结束。现在跑着 agent 或命令的终端在 Solo 退出、更新、重启后都会留下，重新打开后接回原来的进程。
- **Codex 每轮报 "Hook failed"：** Codex 在 Windows 上用 PowerShell 跑 hook，Solo 给的命令它展开不了。现在用完整路径，Codex 的状态来自 hooks，不再靠读屏幕推测。
- **agent 状态有时收不到：** Windows PowerShell 运行程序时会关掉控制台的转义序列处理，hook 的上报被当成普通文字丢掉。
- **移动终端后多出一个分屏：** 移到刚打开的工作区标签时，终端单独占一个窗格。现在会和那个标签已有的终端放在一起。
- **只有行号的链接跳错文件或点不了：** 例如 "(:3788)"，现在按"文件存在、而且有这一行"选对的文件。
- **工作区外的裸文件名点不开：** 终端在不属于任何工作区文件夹的目录里时，也会在它自己的目录下找文件。
- **同一个终端被恢复两次、关掉的终端留下后台进程：** 已修。
- **右键驱动器"通过 Solo 打开"打不开：** 已修。

## 改进

- **状态红绿灯：** 失败红、等你回复黄、完成待看绿、工作中蓝，形状也各不相同；终端标签、工作区标签、Agent 看板统一。终端标签显示 agent 图标、会话名和上下文圆环；悬停卡片和底部用量栏重做；agent 终端不再挂一个响铃蓝点。
- **去掉"上下文快满了"的弹窗：** 只靠颜色提示。
- **关掉所有终端后：** 终端栏显示空状态，可以一步新建终端、Claude Code 或 Codex 终端，或者查找文件。
- **终端不在本标签的文件夹里时：** 标签上有标记，顶部提示条可以移到对应的标签或留在这里；右键菜单可以随时"移到标签"；拆分工作区改成对话框，逐个选终端去哪。
- **右键菜单"通过 Solo 打开"：** 安装时默认加上，文件、文件夹、文件夹空白处、驱动器都有；卸载时删除。
- **边输边补全：** 没用过的命令也会弹出补全，灰色提示也来自补全规格。
- **"# 想做的事"生成命令：** 生成时不再能执行任何工具，更快，带上最近一条失败的命令和输出，也支持 Codex。
- **语言服务：** 状态栏显示内存占用，可以按项目暂停后台分析或关掉；大仓库打开时提醒一次；启动失败时说清缺什么。
- **OpenCode：** 状态准确上报，重启后接回原来的会话。
- **设置页：** 去掉每一项前面的"复制链接"按钮。
- **去掉 Zed 自带的智能体面板和线程侧栏：** Solo 让 agent 在终端里跑。
- **安全：** agent 状态上报需要终端的密钥；"拒绝"不会删掉本轮之前就有的文件，删除改为移到回收站；回滚不会穿过目录链接；没信任的项目不运行 `.solo/tasks.json` 里的命令；更新包缺少校验值时不安装。

## Fixes

- **An update and restart ended running agents:** when Solo quit slowly, programs in its terminals were ended early. Terminals running an agent or a command now survive Solo quitting, updating and restarting, and reconnect to the same processes.
- **Codex reported "Hook failed" every turn:** Codex runs hooks with PowerShell on Windows, which couldn't expand Solo's command. It's now a full path, and Codex's status comes from its hooks instead of reading the screen.
- **Agent status was sometimes lost:** Windows PowerShell turns off escape-sequence processing while it runs a program, so hook reports were printed as text and dropped.
- **Moving a terminal added a split:** moving it to a workspace tab that had just opened put it in a pane of its own. It now joins that tab's terminals.
- **Line-only links like "(:3788)" went to the wrong file or didn't work:** the file that exists and has that line is chosen.
- **Bare file names outside the workspace didn't open:** a terminal in a folder no workspace holds also looks in its own folder.
- **A terminal restored twice, and closed terminals leaving background processes:** fixed.
- **"Open with Solo" on a drive didn't open:** fixed.

## Improvements

- **Traffic-light status:** failed red, waiting for you yellow, done and unseen green, working blue, each with its own shape, the same on terminal tabs, workspace tabs and the agent board. Terminal tabs show the agent's icon, the session name and a context ring; the hover card and usage bar are redone; agent terminals no longer keep a blue bell dot.
- **No more "context nearly full" popup:** colour shows it instead.
- **After closing every terminal:** the terminal column shows an empty state to start a terminal, a Claude Code or Codex terminal, or find a file.
- **A terminal outside its tab's folders:** gets a mark on its tab and a banner to move it to the right tab or keep it; Move to Tab is on the tab's menu; splitting a workspace is a dialog where you choose where each terminal goes.
- **"Open with Solo" in Explorer's context menu:** added by the installer by default for files, folders, folder backgrounds and drives; removed on uninstall.
- **Completions as you type:** also for commands you haven't used, and the grey suggestion comes from command specs too.
- **"# what you want" command generation:** can't run tools while generating, is faster, includes the last failed command and its output, and works with Codex.
- **Language servers:** memory use in the status bar, per-project pause or off, a one-time warning on big repositories, and clear reasons when one fails to start.
- **OpenCode:** accurate status, and its session resumes after a restart.
- **Settings:** no more "copy link" button before each item.
- **Zed's agent panel and threads sidebar are gone:** Solo runs agents in terminals.
- **Security:** agent status reports need the terminal's key; Reject never deletes files that existed before the turn, and deletes go to the recycle bin; rollback doesn't follow directory links; untrusted projects don't run `.solo/tasks.json` commands; updates without a checksum aren't installed.
