Solo 2.5.6: local voice input, pull request follow-up on the task board, finding and installing agents, New Web Page, a preview menu for HTML, table, SVG and PDF links in the terminal, plus improvements to terminal links and remote development.

下载：[GitHub 安装程序](https://github.com/lucas9801/solo/releases/latest/download/Solo-Setup.exe)（下面附件里的 `Solo-Setup-2.5.6.exe` 是同一个文件；未签名，运行时点"更多信息"→"仍要运行"） · [Microsoft Store](https://get.microsoft.com/installer/download/9NBW452JVWN6)。`.gz` 附件是远程开发用的 Linux 服务端，不是安装包。 · [用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

## 新功能

- **语音输入：** 终端输入框的麦克风按钮或 Ctrl+Alt+M 把说的话转成文字。识别模型只下载一次，在本机运行，不联网也能用；Esc 取消，空闲五分钟后模型自动卸载。
- **看板跟进 PR：** 每个任务的 PR 通过 gh 检查，看板显示检查失败、新的审阅评论和可以合并，并能把它们发给 agent。agent 不能接收多行粘贴时会说明原因，并把反馈复制到剪贴板。
- **查找和安装 agent：** "+"菜单和空的终端列会列出本机装好的 agent；"安装 agent"列出其余的，并把安装命令填进新终端，由你自己运行。
- **新建网页：** 编辑器窗格"+"菜单里的"新建网页"打开一个空的网页标签。
- **预览菜单：** 在终端里点 HTML、表格、SVG、PDF 文件，会问你要在 Solo 里预览、用浏览器打开还是打开源文件。远程项目照旧打开文件。

## 改进和修复

- **终端链接：** 程序把行号折到下一行时，Ctrl+点击也能打开对应位置；全角标点后面的行号也能识别。
- **远程开发：** 下载远程服务端遵循下载设置，并先征求同意；从远程项目打开 localhost 链接时，会说明打开的是本机的端口。
- **网页挡住界面：** 提示、拖动预览、关闭对话框和语音输入卡片不再被网页挡住。
- **系统通知：** Windows 上弹系统通知时不再在日志里报错。
- **看板：** 启动或退出 agent 后任务行自动更新；看板窄时"发给 agent"按钮保持可见；路径提示不再挡住 PR 菜单。

## New

- **Voice input:** the microphone button in the terminal input, or Ctrl+Alt+M, turns speech into text. The recognition model is downloaded once and runs on this computer, offline too; Esc cancels, and the model is unloaded after five idle minutes.
- **Pull request follow-up on the board:** each task's pull request is checked through gh. The board shows failed checks, new review comments and when it's ready to merge, and sends them to the agent. When the agent can't take a pasted message of several lines, Solo says so and copies the feedback to the clipboard.
- **Find and install agents:** the + menu and the empty terminal column list the agents installed on this computer, and Install Agents shows the rest, filling the install command into a new terminal for you to run.
- **New Web Page:** New Web Page in the editor pane's + menu opens an empty web page tab.
- **Preview menu:** clicking an HTML, table, SVG or PDF file in the terminal asks whether to preview it in Solo, open it in the browser or open the source. Remote projects open files as before.

## Improvements and fixes

- **Terminal links:** Ctrl+click opens a file position whose line number the program wrapped onto the next line, and a line number after full-width punctuation.
- **Remote development:** downloading the remote server follows the download settings and asks first; a localhost link opened from a remote project notes that it opens this computer's port.
- **Web pages hiding the interface:** tooltips, the drag preview, the close dialog and the voice input card are no longer hidden behind a web page.
- **System notifications:** showing a system notification on Windows no longer logs an error.
- **Board:** task rows update when an agent starts or exits, the Send to Agent button stays visible on a narrow board, and the path tooltip no longer covers the pull request menu.
