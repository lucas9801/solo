Solo 2.5.1：下载前先询问并可切到离线模式，agent 能用 Solo 的代码分析工具，Codex 的改动按文件归到它自己的轮次，另有一批稳定性和安全修复。
Solo 2.5.1: Solo asks before downloading and has an offline mode, agents can use Solo's code intelligence tools, Codex's edits are counted as its own per file, and a set of stability and security fixes.

[用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

## 新功能

- **下载前先询问：** 语言服务、Node.js、Prettier、调试器、Copilot、扩展更新第一次下载前，Solo 会问一次，写明从哪里下载，可以允许并记住、暂不下载或指定本机路径。设置 `downloads.mode` 可选 ask（默认）、auto、never。不信任的项目即使设成 auto 也会先问。
- **离线模式：** 状态栏右侧的按钮或设置 `network.offline`。打开后 Solo 只访问本机和局域网，不再安装任何东西，已经装好的语言服务等照常使用。设置 › 通用 › 网络和下载 里也能改。
- **给 agent 的代码分析工具：** Solo 终端里的 Claude Code 和 Codex 能调用 Solo 已经在跑的语言服务：查找符号、跳到定义、查找引用、看诊断，都是只读的，只限当前工作区。设置 `terminal.ide_tools` 可以关掉。
- **Codex 的改动归到它自己的轮次：** Solo 从 Codex 发来的运行记录里读出它改了哪些文件，一轮的审阅只列这些文件，同一时间你或别的程序改的文件单独列出，"全部拒绝"不会动它们。不用额外配置，也不会让 Codex 变慢。

## 修复

- **开了系统代理时：** agent 连 Solo 的本机地址（代码分析工具、Codex 的运行记录）不再走代理，以前会连不上。
- **Codex 启动时：** 不再提示"无法识别的设置"。
- **跨仓库的任务：** 任务文件夹里的各个工作树也有快照，agent 在里面的改动能显示、拒绝、回滚和撤销。
- **审阅：** 读取改动更快；快照库超过 4 GB 时会清空。
- **稳定：** 终端托管进程在客户端不读数据时不再卡住，收不到开头信息时会放弃重连；很长的会话记录分段读取。
- **安全：** 网络路径不会在渲染和补全里被访问；交给 agent 的拉取请求评论里，别人写的会标为"未核实"。

## New

- **Ask before downloading:** before the first download of a language server, Node.js, Prettier, a debug adapter, Copilot or an extension update, Solo asks once and names where it comes from; you can allow and remember it, skip it for now or point to a local path. The `downloads.mode` setting is ask (default), auto or never. Untrusted projects are asked even in auto mode.
- **Offline mode:** a button at the right of the status bar, or the `network.offline` setting. Solo then reaches only this computer and the local network and installs nothing, while what's already installed keeps working. Also in Settings › General › Network and Downloads.
- **Code intelligence for agents:** Claude Code and Codex in Solo's terminals can use the language servers Solo already runs to find symbols, go to definitions, find references and read diagnostics, read-only and limited to the workspace. Turn it off with `terminal.ide_tools`.
- **Codex's edits count as its own:** Solo reads which files Codex changed from the telemetry Codex sends it, so a turn's review lists only those files, and files you or other programs changed at the same time are listed apart and left alone by Reject All. No setup, and Codex doesn't get slower.

## Fixes

- **With a system proxy:** agents reach Solo's local addresses (the code intelligence tools, Codex's telemetry) without going through the proxy; before, they couldn't connect.
- **Codex at startup:** no more "unrecognized setting" warning.
- **Tasks across repositories:** the worktrees in a task's folder are snapshotted too, so an agent's changes in them can be shown, rejected, rolled back and restored.
- **Review:** reading changes is faster; snapshot stores over 4 GB are emptied.
- **Stability:** terminal hosts no longer stall when a client stops reading and give up on a client that never sends its header; very long session logs are read a piece at a time.
- **Security:** network paths aren't touched while rendering or suggesting; pull request comments by other people are marked unverified when given to an agent.
