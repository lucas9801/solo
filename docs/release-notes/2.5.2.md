Solo 2.5.2：下载前先询问并可切到离线模式，agent 能用 Solo 的代码分析工具，Codex 的时间线和改动统计变准，GitHub 上重新提供安装程序，另有一批界面和稳定性修复。
Solo 2.5.2: Solo asks before downloading and has an offline mode, agents can use Solo's code intelligence tools, Codex's timeline and edits are accurate again, GitHub releases have an installer again, and a set of interface and stability fixes.

下载：[Microsoft Store（推荐）](https://get.microsoft.com/installer/download/9NBW452JVWN6) · 下面附件里的 `Solo-Setup-2.5.2.exe`（未签名，运行时点"更多信息"→"仍要运行"）。`.gz` 附件是远程开发用的 Linux 服务端，不是安装包。 · [用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

## 新功能

- **下载前先询问：** 语言服务、Node.js、Prettier、调试器、Copilot、扩展更新第一次下载前，Solo 会问一次，写明从哪里下载，可以允许并记住、暂不下载或指定本机路径。设置 `downloads.mode` 可选 ask（默认）、auto、never。不信任的项目即使设成 auto 也会先问。
- **离线模式：** 状态栏右侧的按钮或设置 `network.offline`。打开后 Solo 只访问本机和局域网，不再安装任何东西，已经装好的语言服务等照常使用。
- **给 agent 的代码分析工具：** Solo 终端里的 Claude Code 和 Codex 能调用 Solo 已经在跑的语言服务：查找符号、跳到定义、查找引用、看诊断，都是只读的，只限当前工作区。设置 `terminal.ide_tools` 可以关掉。
- **Codex 的改动归到它自己的轮次：** Solo 从 Codex 发来的运行记录里读出它改了哪些文件，一轮的审阅只列这些文件，同一时间你或别的程序改的文件单独列出，"全部拒绝"不会动它们。
- **GitHub 安装程序：** 发布页重新提供 `Solo-Setup-<版本>.exe`，可以选安装目录，由 Solo 自己更新；用旧安装包装的 Solo 也能自动更新到这一版。首推仍是 Microsoft Store。
- **设置能搜中文：** 搜"代理""内存"这类中文标题和说明也能找到对应设置。

## 修复

- **Codex 时间线：** 新版 Codex 的会话以前只显示最后一个回答；现在每个提问单独一段，带图片的提问标出 [image]，命令和改过的文件也会显示。
- **开了系统代理时：** agent 连 Solo 的本机地址（代码分析工具、Codex 的运行记录）不再走代理，以前会连不上。
- **Codex 启动时：** 不再提示"无法识别的设置"。
- **终端：** 安装包和商店包重新带上新版 ConPTY（conpty.dll、OpenConsole.exe），以前的包里漏了，终端用的是 Windows 自带的旧版。
- **终端标签右键菜单：** 去掉只对编辑器有用的项；"移到标签"改为"移到工作区"。
- **界面：** 终端工具栏不再显示用不了的"内联辅助"（配置了模型时才出现），终端里的 `Ctrl+I` 交还给 shell；编辑区的"+"菜单不再有新建终端；设置里"内存超过 … GB 时提醒"那一行排版修好。
- **去掉用不上的部分：** 协作、云端模型和遥测的代码全部删掉；界面里残留的旧名称改成 Solo；不再提供注册 zed:// 链接的命令。
- **跨仓库的任务：** 任务文件夹里的各个工作树也有快照，agent 在里面的改动能显示、拒绝、回滚和撤销。
- **稳定和安全：** 终端托管进程在客户端不读数据时不再卡住；很长的会话记录分段读取；网络路径不会在渲染和补全里被访问；交给 agent 的拉取请求评论里，别人写的会标为"未核实"。

**环境变量改名：** 以 `ZED_` 开头的环境变量改成了 `SOLO_` 开头，例如 `ZED_LOG` → `SOLO_LOG`、Bedrock 凭据和 `ZED_WINDOW_SIZE` 等界面调试变量。自己设置过的话请改名；`ZED_STATELESS` 和 `ZED_GENERATE_MINIDUMPS` 仍然认。任务里的 `$ZED_FILE` 这类变量不变。

## New

- **Ask before downloading:** before the first download of a language server, Node.js, Prettier, a debug adapter, Copilot or an extension update, Solo asks once and names where it comes from; you can allow and remember it, skip it for now or point to a local path. The `downloads.mode` setting is ask (default), auto or never. Untrusted projects are asked even in auto mode.
- **Offline mode:** a button at the right of the status bar, or the `network.offline` setting. Solo then reaches only this computer and the local network and installs nothing, while what's already installed keeps working.
- **Code intelligence for agents:** Claude Code and Codex in Solo's terminals can use the language servers Solo already runs to find symbols, go to definitions, find references and read diagnostics, read-only and limited to the workspace. Turn it off with `terminal.ide_tools`.
- **Codex's edits count as its own:** Solo reads which files Codex changed from the telemetry Codex sends it, so a turn's review lists only those files, and files you or other programs changed at the same time are listed apart and left alone by Reject All.
- **GitHub installer:** releases have `Solo-Setup-<version>.exe` again; you can choose the install folder and Solo updates itself, and Solo installed with an earlier installer updates to this version. The Microsoft Store is still the first choice.
- **Settings search in Chinese:** Chinese titles and descriptions such as 代理 or 内存 now find their settings.

## Fixes

- **Codex timeline:** sessions from newer Codex versions showed only the last answer; now each prompt has its own section, prompts with images are marked [image], and commands and changed files show up.
- **With a system proxy:** agents reach Solo's local addresses (the code intelligence tools, Codex's telemetry) without going through the proxy; before, they couldn't connect.
- **Codex at startup:** no more "unrecognized setting" warning.
- **Terminals:** the installer and the Store package include the newer ConPTY again (conpty.dll, OpenConsole.exe); earlier packages left them out, so terminals used Windows' older one.
- **Terminal tab menu:** entries that only make sense for editors are gone, and "Move to Tab" is now "Move to Workspace".
- **Interface:** the terminal toolbar no longer shows Inline Assist unless a model is configured, and `Ctrl+I` in a terminal goes to the shell again; the editor's + menu no longer has new terminal entries; the "alert when memory exceeds … GB" settings row is laid out on one line.
- **Leftovers removed:** the collaboration, hosted model and telemetry code is gone, remaining old names in the interface now say Solo, and the command that registered zed:// links is gone.
- **Tasks across repositories:** the worktrees in a task's folder are snapshotted too, so an agent's changes in them can be shown, rejected, rolled back and restored.
- **Stability and security:** terminal hosts no longer stall when a client stops reading; very long session logs are read a piece at a time; network paths aren't touched while rendering or suggesting; pull request comments by other people are marked unverified when given to an agent.

**Renamed environment variables:** variables starting with `ZED_` now start with `SOLO_`, for example `ZED_LOG` → `SOLO_LOG`, the Bedrock credentials and interface debugging ones such as `ZED_WINDOW_SIZE`. Rename them if you set any; `ZED_STATELESS` and `ZED_GENERATE_MINIDUMPS` still work. Task variables such as `$ZED_FILE` are unchanged.
