Solo 2.4.1：修复微软商店版安装包被商店拒收的问题；从 GitHub 安装的 Solo 没有变化。
Solo 2.4.1: fixes the Microsoft Store package that the Store rejected; Solo installed from GitHub is unchanged.

[用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

## 修复

- **商店拒收安装包：** 包里除了 Solo 还有两个不在开始菜单显示的程序（solo-cli 和 agent 状态上报程序），商店不接受。现在包里只有 Solo；这两个程序由 Solo 复制到数据目录，更新后路径不变。商店版里 `solo-cli` 只在 Solo 的终端里能用。
- **2.4.0 的 Linux 远程服务器一开始没有发布：** 发版时版本号文件的换行格式让检查读错了版本，已修，以后不会再出现。

## Fixes

- **The Store rejected the package:** besides Solo it had two programs without a Start menu entry (solo-cli and the agent status reporter), which the Store doesn't accept. The package now has only Solo, which copies the two programs to its data folder, where their paths stay the same across updates. In the Store edition, `solo-cli` works only in Solo's terminals.
- **2.4.0's Linux remote servers were missing from its release at first:** the version file's line endings made a check misread the version when releasing. Fixed for future releases.
