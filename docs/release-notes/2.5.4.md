Solo 2.5.4：终端找得到 claude 和 codex 了，更新重启后终端回到自己的标签并认得出 agent，正常退出前会先问，终端里的链接不会再运行程序，另有新的更新按钮和一批修复。
Solo 2.5.4: terminals find claude and codex again, kept terminals return to their own tabs and are recognized after an update restart, quitting asks before ending agents, terminal links never run programs, plus a new update button and more fixes.

下载：[GitHub 安装程序](https://github.com/lucas9801/solo/releases/latest/download/Solo-Setup.exe)（下面附件里的 `Solo-Setup-2.5.4.exe` 是同一个文件；未签名，运行时点"更多信息"→"仍要运行"） · [Microsoft Store](https://get.microsoft.com/installer/download/9NBW452JVWN6)。`.gz` 附件是远程开发用的 Linux 服务端，不是安装包。 · [用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

## 修复

- **终端里找不到 claude、codex：** 用户 PATH 很长时，从任务栏或开始菜单打开的 Solo 拿不到它，终端里 `claude`、`codex` 报"找不到命令"。现在新开的终端和 Windows Terminal 一样，从系统读取当前的 PATH 等环境变量，Solo 开着时新装的程序也能找到。找不到时只打印一行提示。
- **更新重启后终端跑到当前标签：** 还没点开的项目标签里保留运行的终端，以前会被挪进当前标签，自己的标签里还多出一个空终端。现在它们回到自己的标签。
- **重连回来的终端认不出 agent：** 更新重启或崩溃后接回的终端，以前没有状态点、标题是 powershell.exe。现在能认出里面在跑的 claude、codex，状态、标题、按轮审阅和关闭提示都照常。
- **重启后终端面板的"+"变成编辑器菜单：** 现在每个终端窗格的"+"都是新建终端的菜单。
- **按轮快照存了没跟踪的大文件：** 超过 50 MB 的未跟踪文件不再进快照，审阅里会注明；旧快照自动清理，总共不超过 4 GB。
- **终端链接的安全：** 终端里的 `file:` 链接（包括程序输出的超链接）一律在 Solo 里打开，不会再运行程序；只有 http、https、mailto 会交给系统打开，`ssh:`、`ftp:`、`magnet:` 等协议的链接不再能点击；`\\server\share` 这类网络路径不再显示为链接，悬停时也不会去访问别的电脑。
- **启动时：** 没有配置本地模型时，不再去连 localhost 的 8080 和 1234 端口。

## 改动

- **正常退出先问：** 菜单退出、关最后一个窗口、标题栏 ×、Alt+F4 时，有在跑的 agent 会先问，确认后结束它们（没点开的项目标签里的也会列出）。更新重启和崩溃照旧不打断 agent。设置 `terminal.keep_running_on_quit` 现在只管正常退出，默认改为 false；设成 true 就和以前一样不问、继续跑。Windows 上的终端现在总是跑在托管进程里。
- **新的更新按钮：** 标题栏的更新按钮改成胶囊样式，带下载进度；选了"退出时安装"后按钮隐藏；每小时检查一次更新（以前是 6 小时）。
- **结果标签的标题：** 查找引用、定义、实现等结果标签的标题跟随界面语言。

## Fixes

- **claude and codex not found in terminals:** with a long user PATH, Solo started from the taskbar or Start menu didn't get it, so `claude` and `codex` weren't found. New terminals now read the current PATH and other variables from the system, like Windows Terminal, so programs installed while Solo runs are found too. A missing program prints one short line.
- **Terminals moved into the current tab after an update restart:** kept terminals of project tabs not opened yet were moved into the current tab, and their own tab got an extra empty terminal. They now return to their own tabs.
- **Reconnected terminals didn't recognize their agent:** terminals reconnected after an update restart or a crash had no status and were titled powershell.exe. Solo now recognizes the claude or codex running in them, so status, titles, per-turn review and the close prompt work as usual.
- **The terminal panel's "+" showed the editor menu after a restart:** every terminal pane's "+" is the terminal menu again.
- **Turn snapshots stored large untracked files:** untracked files over 50 MB aren't snapshotted and the review says so; old snapshots are cleaned up automatically, 4 GB at most in all.
- **Terminal link safety:** `file:` links in the terminal (including hyperlinks printed by programs) always open in Solo and never run a program; only http, https and mailto go to the system, so ssh:, ftp:, magnet: and other links aren't clickable anymore; network paths such as `\\server\share` aren't links and hovering never reaches another computer.
- **At startup:** Solo no longer connects to localhost ports 8080 and 1234 when no local model is set up.

## Changes

- **Quitting asks first:** quitting from the menu, closing the last window, the title bar × or Alt+F4 asks when agents are running and ends them after you confirm (agents in project tabs not opened yet are listed too). Update restarts and crashes still keep agents running. The `terminal.keep_running_on_quit` setting now only governs a normal quit and defaults to false; set it to true to keep the old behavior. On Windows, terminals now always run in a terminal host.
- **New update button:** the title bar's update button is a pill with download progress, hides after you choose "Install When Solo Quits", and Solo checks for updates every hour instead of every six.
- **Result tab titles:** references, definitions, implementations and similar result tabs are titled in the interface language.
