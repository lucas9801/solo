Solo 2.4：显示 agent 的首字时间和输出速度，重新连接时恢复终端画面，界面文字重写得更短更统一。
Solo 2.4: agents' time to first token and output speed are shown, terminals get their screen back when reconnecting, and the interface text is shorter and consistent.

[用户指南](https://github.com/lucas9801/solo/blob/main/docs/guide/zh-CN.md) · [User guide](https://github.com/lucas9801/solo/blob/main/docs/guide/en.md)

Solo 的源码搬到了新仓库 lucas9801/solo，从这个版本起在这里发布；已装的 Solo 照常收到更新。

## 改进

- **agent 的速度：** 底部用量栏和标签的悬停卡片显示模型和推理强度、首字时间、输出速度和这一轮用了多久。支持 Claude Code、Codex、Copilot CLI 和 OpenCode；测不准的值不显示。
- **重新连接时恢复画面：** Solo 重启后接回终端，看到的是原来的完整画面，不再只有最后几行输出。没人在用的后台终端会在启动时找回来，或者提示你结束它们。
- **界面文字：** 名称直接说功能，说明最多一句；中文统一用"agent"和"工作树"。
- **终端通知分开设置：** "agent 停止工作"的通知默认关闭；agent 需要输入、程序通知、长命令各有自己的开关。
- **语言服务设置页：** 设置 > 语言服务里定每个语言服务做多少事；状态栏菜单一键切换；语言服务占内存多时提醒。
- **+ 菜单：** 可以在新的工作树里开终端、运行工作流；终端栏可以从标签栏隐藏，活动栏再打开。
- **agent 图标用各自的颜色；** 工作区标签只显示状态。
- **安全：** 回滚中途失败时保留撤销点；一轮只算 agent 自己改的文件；会连到 Solo 外部的 solo:// 链接（SSH、git clone）先询问。

## 修复

- **装在不同位置的 Solo 共用一个 Claude Code 设置文件：** 现在每个 hook 路径各用一个。

## Improvements

- **Agent speed:** the usage bar and the tab's hover card show the model and effort, time to first token, output speed and how long the turn took, for Claude Code, Codex, Copilot CLI and OpenCode; values that can't be measured reliably aren't shown.
- **The screen comes back on reconnect:** after a restart a terminal shows its whole screen again, not just the last lines of output. Background terminals nobody is using are found on startup, or you're offered to end them.
- **Interface text:** labels name the feature and descriptions are one short sentence at most.
- **Separate terminal notification settings:** agent "stopped working" notifications are off by default; agent input requests, program notifications and long commands each have their own switch.
- **Language Services settings page:** set how much each language server does; switch levels from the status bar in one click; an alert when language servers use a lot of memory.
- **The + menu:** opens a terminal in a new worktree and runs workflows; the terminal column can be hidden from its tab bar and shown again from the activity bar.
- **Agent logos in their own colours;** workspace tabs show status only.
- **Security:** a rollback that fails partway keeps the undo point; a turn only counts files the agent itself changed; solo:// links that reach outside Solo (SSH, git clone) ask first.

## Fixes

- **Copies of Solo installed in different places shared one Claude Code settings file:** each hook path now has its own.

Solo's source moved to the new repository lucas9801/solo, and releases come from there from this version on; installed copies of Solo keep updating as usual.
