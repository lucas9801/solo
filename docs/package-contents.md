# What Solo's package contains / 安装包内容

Every file in Solo Code's Microsoft Store package, made by
[`script/package-solo-msix.ps1`](../script/package-solo-msix.ps1) from the
files staged by [`script/package-solo.ps1`](../script/package-solo.ps1)
(`dist\Solo`), with where it comes from and its license. Versions are those
of Solo 2.2.0. The package also holds its manifest and icons. The Store signs
the package; the files in it aren't signed separately. Releases have no other
Windows download (no installer, no zip).

Solo Code 的 Microsoft Store 安装包里的每个文件，由 `script/package-solo-msix.ps1` 用 `script/package-solo.ps1` 准备的文件（`dist\Solo`）打包，列出来源和许可证。版本以 Solo 2.2.0 为准。安装包里另有清单和图标。安装包由 Store 签名，里面的文件不单独签名。发布里没有别的 Windows 下载（没有安装程序，也没有 zip）。

## Components to watch / 需要注意的组件

No proprietary (closed-source) component was found. These are worth
knowing about:

没有发现专有（闭源）组件。以下几项值得注意：

1. **CDLA-Permissive-2.0** (`webpki-roots`, `webpki-root-certs`: Mozilla's
   root certificate list as data). An open data license, not on the OSI list.
   It's data, not code.
   ——开放数据许可，不在 OSI 列表上；是数据不是代码。
2. **ConPTY download**: `crates/zed/build.rs` downloads the NuGet package
   over HTTPS and checks its SHA-256 against a fixed value (the digest
   GitHub shows for the release asset); another hash stops the build. The
   files are Microsoft-signed as well. (Done; Zed doesn't check it.)
   ——构建时下载的 ConPTY 包按固定的 SHA-256 校验（与 GitHub 上该发布文件的摘要一致），不一致就构建失败；文件本身也有微软签名。（已完成）
3. **Sounds** (`assets/sounds/*.wav`) come from Zed's repository with no
   license of their own, so they fall under the repository's license.
   ——音效文件来自 Zed 仓库，没有单独许可证，按仓库许可证。
4. **Version resources**: all five of Solo's exes carry the same version
   information (`crates/windows_resources`): product name "Solo", and Solo's
   version (`crates/zed/Cargo.toml`) as product and file version, whatever
   the version of the crate they're built from; `solo-package.yml` checks
   them after building.
   ——五个 exe 都带同样的版本信息：产品名 Solo，产品版本和文件版本都是 Solo 的版本；打包工作流构建后检查。

Herdr's Apache-2.0 license text is included in `licenses.md` (added with
this list; before, only `THIRD-PARTY-VENDORED.md` mentioned it).
